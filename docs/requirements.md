# Task 2 (Easy) – Student Management System

## **Description :** Build a full-stack application to manage student records and information.

### Task Workflow

Step 1: Design the frontend interface.  
Step 2: Create backend APIs.  
Step 3: Implement database connectivity.  
Step 4: Add CRUD operations.  
Step 5: Test application functionality.  

### Skills You Will Learn

- Frontend Development
- Backend Development
- Database Management
- REST APIs

### Key Features

- Add Students
- Update Records
- Delete Records
- View Student Details
